# JAX

This is a placeholder page for the JAX documentation set. Real content will be populated by `ingest sync --only jax` in a later phase.

## What goes here

When the ingest pipeline runs, this directory will be filled with MDX files converted from the upstream Sphinx HTML build. The sidebar will be auto-generated from the directory structure, and a `_manifest.json` will be emitted alongside the docs so the Codex library sidebar can pick the package up.

This page exists so Phase 1 has something to render while the ingest CLI is still under construction.
